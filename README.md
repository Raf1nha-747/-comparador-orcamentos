# Comparador de Orçamentos

Script em Python que lê orçamentos de fornecedores e identifica o menor preço de cada produto.

## Ferramentas
Python, pandas

## O que o código faz
- Agrupa os preços por produto
- Encontra o fornecedor mais barato de cada um
- Calcula o preço médio por produto
- Calcula a economia estimada ao escolher sempre o mais barato

## Como usar
Coloque os dados em `orcamentos.csv` e rode `python main.py`.

## Contexto
Projeto inspirado na minha experiência com compras e orçamentos na área administrativa.
